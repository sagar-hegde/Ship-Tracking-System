# 🚢 Ship Tracking System

A modern **real-time ship tracking web application** designed to improve maritime safety, operational efficiency, and user experience. This system enables users to track ships, report incidents, and access live maritime data through an intuitive and responsive interface.

---

## 📌 Overview

The **Maritime Tracking System (MTS)** is built to overcome limitations of traditional tracking systems by providing:

* Real-time ship monitoring
* Interactive map visualization
* Accident reporting system
* Subscription-based tracking features

It ensures **accurate, fast, and reliable tracking** of maritime operations using modern web technologies and APIs.

---

## 🚀 Key Features

* 🌍 **Real-Time Ship Tracking** – Track ships using unique Ship ID
* 🗺️ **Interactive Map Integration** – Visualize ship movements on live maps
* ⚡ **Instant Updates** – Live position and route updates
* 🔍 **Advanced Filtering** – Search by source, destination, date, and time
* 🚨 **Accident Reporting System** – Report maritime incidents easily
* 💳 **Subscription Plans** – Free, Basic, Premium & Premium Plus
* 👤 **User-Friendly Interface** – Clean, responsive UI for seamless experience

---

## 🧠 Problem Statement

Traditional ship tracking systems suffer from:

* Lack of real-time updates
* Manual data errors
* Inefficient communication
* Data overload

This project solves these issues using **automation, APIs, and real-time data processing**.

## 🏗️ System Architecture

The system allows users to:

* Enter Ship ID → Track ship
* Login → Access full tracking features
* Report incidents → Store and process data
* View results on interactive dashboard
